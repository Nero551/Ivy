Detailed Description

template<IsComponent T>
struct Ivy::C::ComponentPool< T >

Stores components using a sparse set.

Provides O(1) component lookup by entity ID while keeping components densely packed for efficient iteration.

Automatically removes components when their associated entity is destroyed.

TComponent type stored by the pool.
