Detailed Description

A math library for the Ivy game engine. Mainly contains:

  • Vectors (Vector)
  • Matrices (Matrix)
  • Complex numbers (Complex)
  • Quaternions (Quaternion)
  • Multi-variable/valued functions (Function)
  • Linear system of equations solver (LinearSystem | LinearEquation).
  • ODE solver (explicit euler only) (ODE).
