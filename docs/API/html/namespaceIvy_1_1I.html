enum class Ivy::I::MouseMode
strong

Specifies how the mouse cursor is handled by the window.

Enumerator
Normal 

The cursor is visible and unrestricted.

Hidden 

The cursor is hidden but remains unrestricted.

Disabled 

The cursor is hidden and locked to the window.

Captured 

The cursor is visible and confined to the window.
