Detailed Description

Represents a real-valued mathematical function of one variable.

Function provides evaluation, composition, numerical differentiation, numerical integration, inverse evaluation, and arithmetic operations.

Functions can be constructed from any callable satisfying the Func concept.

◆ Taylor()

Function E::M::Function::Taylor ( int terms,
float a )
nodiscard

Creates a Taylor polynomial approximation of the function.

The returned function approximates this function around the specified center point a using the first terms terms of its Taylor series: 

f(a) + f'(a)(x - a) + f''(a)(x - a)^2 / 2! + ...

Each derivative is evaluated at the center point a.

Note that terms specifies the number of terms, not the highest polynomial degree. For example, Taylor(4, a) produces terms of degrees 0 through 3.

Remarks
Since the derivatives are computed numerically, higher-order Taylor approximations will become increasingly affected by numerical error.
Parameters
termsNumber of Taylor series terms to include.
aPoint around which the function is approximated.
