Detailed Description

Base class for all engine modules. Modules provide engine-specific functionality and participate in the engine's lifecycle through protected callback methods. Lifecycle callbacks are invoked by Engine and may be overridden by derived modules to implement initialization, updating, rendering, and shutdown behavior.

Remarks
Order: OnStart -> OnBeginFrame -> OnFixedUpdate -> OnUpdate -> OnRender -> OnEndFrame -> OnStop
