Detailed Description

template<typename T, std::unsigned_integral TypeIdType = unsigned int>
struct Ivy::U::TypedVector< T, TypeIdType >

Vector storage indexed by a unique ID for each template type combination.

Each TypedVector instance assigns TypeIds sequentially as new type combinations are requested. The TypeId is then used directly as the index into the dense storage.
