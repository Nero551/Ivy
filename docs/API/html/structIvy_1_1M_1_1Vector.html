Detailed Description

template<unsigned int Components, Scalar T = float>
struct Ivy::M::Vector< Components, T >

Represents a fixed-size vector of floating-point components.

Provides component-wise arithmetic, scalar arithmetic, vector operations, interpolation, normalization, projection, and comparison.

ComponentsThe number of components in the vector.
