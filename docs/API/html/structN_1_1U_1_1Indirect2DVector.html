Detailed Description

template<typename T>
struct N::U::Indirect2DVector< T >

Indirect two-dimensional storage with dense iteration.

Maps a pair of indices (A, B) to densely packed values. Lookup is O(1) after row/column storage is allocated, while iteration traverses only active values. Erasing uses swap-and-pop, so dense indices can change.
