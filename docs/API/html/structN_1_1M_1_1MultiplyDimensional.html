Detailed Description

template<typename A, typename B>
requires (IsDimensional<A> && IsDimensional<B>)
struct N::M::MultiplyDimensional< A, B >

Represents a compile-time dimensional multiplication expression.

The operands are retained as types, allowing compound dimensions to form recursively. For example, Length<2> * Time<-1> represents m²·s⁻¹.
