Detailed Description

Represents a vector using spherical coordinates.

Spherical coordinates describe a three-dimensional vector using its magnitude and two angles:

  • Elevation: angle above the horizontal plane.
  • Azimuth: angle around the vertical axis.
  • Magnitude: length of the vector.

The angles are expressed in radians.
