Detailed Description

Represents a two-dimensional OpenGL texture resource.

Extends the generic Texture resource with CPU-side pixel data and image loading support for 2D textures.

Member Function Documentation

◆ Generate()

void N::Texture2D::Generate ( )
overridevirtual

Generates the OpenGL 2D texture object.

Creates the texture object, binds it to texture unit 0, applies the configured texture parameters, and uploads the stored pixel data. Mipmaps are generated automatically when AutoMipmaps is enabled.

If the texture has already been generated, no action is taken.

Reimplemented from N::Texture.

◆ UseImage()

void N::Texture2D::UseImage ( const U::Image & image)

Replaces the texture's data and configuration with an image.

Updates the texture dimensions, pixel data, data type, mipmap setting, source format, and internal format based on the image's channel count. The existing GPU texture is not regenerated automatically.

Parameters
imageImage to use as the texture's source data.
Remarks
The image should be vertically flipped when loaded to account for the difference between image and OpenGL texture coordinates.
