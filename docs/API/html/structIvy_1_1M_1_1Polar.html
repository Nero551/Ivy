Detailed Description

template<Scalar T = float>
struct Ivy::M::Polar< T >

Represents a two-dimensional point in polar coordinates. A polar coordinate is represented by an angle and a magnitude:

(r, theta)

where the magnitude represents the distance from the origin and the angle represents the direction measured from the positive x-axis.
