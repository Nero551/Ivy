Detailed Description

Represents the rendering properties and textures of a surface.

A Material defines the shader, color properties, lighting properties, stencil, blending, depth and textures used when rendering an object. It also supports a fixed number of custom texture slots.

A default white texture is assigned to the standard material maps when the material is created.
