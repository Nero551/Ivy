Detailed Description

Validates GLSL shader source using glslang.

ShaderSourceValidator performs offline GLSL validation before the shader is passed to the OpenGL driver for compilation. The validator uses the shader stage and GLSL version provided by the ShaderSource.

This validation is intended as an additional development-time check; OpenGL shader compilation should still be performed because the graphics driver remains the final authority for whether a shader can be compiled.
