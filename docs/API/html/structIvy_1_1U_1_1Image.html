Detailed Description

Represents a raster image.

Stores raw pixel data along with the image dimensions and number of color channels.

void Ivy::U::Image::FlipVertically ( )

Vertically flips the image in place.

Swaps the top and bottom rows of pixels. This is useful when converting between coordinate systems with different vertical origins, such as OpenGL's bottom-left origin and conventional image formats' top-left origin.
