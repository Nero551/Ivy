Detailed Description

template<std::unsigned_integral IndexType = unsigned int, std::unsigned_integral GenType = unsigned int>
struct N::U::GIndexPool< IndexType, GenType >

Manages reusable indices with generation-based handles.

Released indices are reused, while their generation is incremented so that previously issued handles become invalid.
