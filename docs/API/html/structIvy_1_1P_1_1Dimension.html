Detailed Description

template<typename T, typename D>
requires (IsDimensional<D>)
struct Ivy::P::Dimension< T, D >

Associates a runtime value with a compile-time dimensional type.

Template Parameters
TThe underlying value type.
DThe dimensional type associated with the value.

Arithmetic operations preserve dimensional correctness at compile time. Addition and subtraction require equivalent dimensions, while multiplication and division combine and normalize their dimensions.
