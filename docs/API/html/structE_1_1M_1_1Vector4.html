Detailed Description

4D floating-point vector.

Stores four floating-point components: x, y, z, and w.

Vector operations are component-wise unless otherwise specified.

Vector4 can be used as a general 4D mathematical vector or as a homogeneous coordinate when used with Matrix4 transformations.
