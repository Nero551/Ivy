Detailed Description

template<std::unsigned_integral IndexType = unsigned int>
struct Ivy::U::IndexPool< IndexType >

Manages a pool of reusable integer indices.

Indices are acquired and released independently of the objects they identify, allowing external storage to use the indices as stable IDs while released indices are reused by later acquisitions.
