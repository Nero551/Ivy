Detailed Description

template<typename T>
struct N::U::SparseSet< T >

Sparse-indexed storage with densely packed values.

Each sparse index maps to a dense index, allowing O(1) lookup while keeping active entries contiguous. Erasing an entry uses swap-and-pop, so dense indices can change after an erase.

Removes an entry while keeping the dense storage packed.
