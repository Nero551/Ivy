Detailed Description

Owns and manages the runtime state of the engine world. The World owns all entities. It is responsible for managing the lifecycle of entities, including entity creation and destruction & system execution.

Creates and registers an entity in the world.

The entity is assigned a unique ID, initialized, and registered with the world's entity collection. An EntityCreated event is fired after initialization.
