Detailed Description

Represents a vector using hyperspherical coordinates.

Hyperspherical coordinates describe a four-dimensional vector using its magnitude and three angles:

  • Elevation: angle above the horizontal plane.
  • Azimuth: angle around the vertical axis.
  • HyperAngle: angle determining the vector's component along the fourth dimension.
  • Magnitude: length of the vector.

The angles are expressed in radians.
