Detailed Description

template<typename ValueType, typename D>
requires IsDimensional<D>
struct N::M::Dimension< ValueType, D >

Stores a value together with its compile-time dimensional type.

Arithmetic operators preserve dimensional correctness at compile time. Operations on the same dimensional family combine their exponents, while operations on different dimensions construct an operational dimensional type.

Template Parameters
ValueTypeThe type used to store the numerical value.
DThe compile-time dimensional representation of the value.

Multiplies quantities with different dimensional representations.

The resulting dimension is represented as a compile-time multiplication expression rather than combining exponents.

For example, m² * s produces m²·s.
