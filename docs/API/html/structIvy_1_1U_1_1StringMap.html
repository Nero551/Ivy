Detailed Description

template<typename T, std::unsigned_integral IndexType = unsigned int>
struct Ivy::U::StringMap< T, IndexType >

Associates string keys with densely stored values.

Maps string keys to indices in an internal vector, providing key-based lookup while storing values contiguously.

Template Parameters
TType of values stored in the map.
IndexTypeUnsigned integer type used to represent value indices.
Note
Keys are stored as owning std::string objects. Lookups accept std::string_view and use transparent hashing and equality to avoid creating temporary strings.
