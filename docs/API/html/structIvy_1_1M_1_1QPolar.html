Detailed Description

template<Scalar T = float>
struct Ivy::M::QPolar< T >

Represents a quaternion in polar form. A quaternion can be represented as q = m(cos(θ) + u sin(θ)), where m is the magnitude, θ is the angle, and u is the normalized imaginary-axis direction.
